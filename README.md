
# Image Search App

This project is a simple web application that lets you search for images using the Unsplash API. You can enter a search term, see the results, and load more images as you need.

## Features
- Search for images.
- View image details and click to see the original source.
- Load more results as needed.

## Technologies Used
- **HTML** for the structure.
- **CSS** for styling.
- **JavaScript** for fetching and displaying data from the API.

## Getting Started

1. Clone this repository.
2. Replace the `apiKey` in `script.js` with your Unsplash API key.
3. Open `index.html` in your browser to start using the app.

### Getting an Unsplash API Key
1. Go to [Unsplash](https://unsplash.com/).
2. Sign up and navigate to the [Developers section](https://unsplash.com/developers).
3. Create a new app to get your API key.

## Files
- `index.html`: Main page of the app.
- `style.css`: The app's styles.
- `script.js`: Fetches and displays the images.

## How to Use
1. Enter a search term.
2. Click "Search" to see results.
3. Click "Load More" to get more images.
